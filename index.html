📊 엑셀 통합 정리

설정된 요일/시각 이후 관리자가 접속하면 자동으로 엑셀 다운로드를 안내합니다.

📁 처리완료 파일 저장 폴더

바로처리 또는 이체증 업로드 시, 해당 프로젝트의 첨부파일(접수증·고지서·이체증·비고)이 [프로젝트ID]_[현장명]_[차수]차[-N거점]/ 하위 폴더로 자동 저장됩니다.

💻 로컬 폴더 (Windows PC 직접 저장)

폴더를 선택하면 처리 시 Google Drive 없이 PC에 직접 저장됩니다. Chrome / Edge 전용.

미선택
☁️ Google Drive 폴더 (선택)

Apps Script 배포 계정이 이 폴더에 편집자 권한이 있어야 합니다. 로컬 폴더와 동시 저장 가능.

📋 중앙 프로젝트 시트 (시공사별 자동 필터링)

모든 시공사가 공통으로 사용하는 중앙 프로젝트 시트. 로그인한 시공사 이름이 시공사 컬럼에 매칭되는 프로젝트만 표시됩니다. 필요 컬럼: 프로젝트ID, 프로젝트명, 시공사

📐 환경부 출금계좌 참조시트

납부내역 시트의 M·N·O열에 채울 값을 가져오는 별도 시트 (예: PM_25년환경부입찰). 프로젝트ID 컬럼으로 매칭하여 아래 지정한 컬럼 값을 가져옵니다. 비워두면 위 중앙 시트를 사용합니다.

⏳ 납부대기 시트 (시공사 일괄 제출 → 임시 저장)

시공사가 일괄 제출하면 우선 이 시트로 들어가고, 관리자가 확인완료를 누르면 처리 결과 기록 시트로 이동합니다. 처리 결과 기록 시트와 컬럼 구조가 동일해야 합니다.

📝 처리 결과 기록 시트 (납부 이력)

처리완료 시 자동으로 행이 추가되는 시트. 납부 이력 탭에서도 이 시트를 읽어옵니다.

🔐 시공사 계정 관리

중앙 프로젝트 시트를 쓰면 개별 시트 URL은 비워두세요. 시공사 이름은 중앙 시트의 시공사 컬럼 값과 일치해야 매칭됩니다.

☁️ 클라우드 동기화 (Google Sheets)

Google Apps Script URL을 입력하면 모든 시공사 데이터가 Google Sheet와 Drive에 자동 동기화됩니다. 설정 방법은 apps-script/설치가이드.md 파일을 참고하세요.

⚠️ 데이터 관리

모든 제출 데이터, 첨부 파일, 프로젝트 매핑이 삭제됩니다.
