# Google Sheets 연동 설치 가이드

웹사이트 데이터를 Google Sheet 에 자동 동기화하고, 첨부 파일을 Google Drive 에 자동 업로드하는 방법입니다.

## 1. Google Sheet 생성

1. [sheets.new](https://sheets.new) 접속 → 새 스프레드시트 생성
2. 이름을 `한전불입금_관리` 로 변경

## 2. Apps Script 설정

1. 스프레드시트 상단 메뉴 → **확장 프로그램 → Apps Script** 클릭
2. 기본으로 나오는 `Code.gs` 내용을 전부 삭제
3. 이 폴더의 `Code.gs` 파일 내용을 전부 복사해서 붙여넣기
4. 상단 프로젝트 이름 `무제 프로젝트` 를 `한전불입금_백엔드` 로 변경
5. 💾 저장 (Ctrl+S)

## 3. 웹 앱으로 배포

1. 우측 상단 **배포 → 새 배포** 클릭
2. 톱니바퀴 아이콘 → **웹 앱** 선택
3. 설정:
   - 설명: `한전불입금 관리 API`
   - 다음 사용자로 실행: **나** (본인 계정)
   - 액세스 권한: **모든 사용자** (로그인 없이도 웹사이트가 호출 가능하게)
4. **배포** 클릭
5. 권한 승인 요청이 뜨면 → **액세스 승인** → 본인 계정 선택 → 고급 → 안전하지 않음으로 이동 → 허용
6. 배포 완료 후 나오는 **웹 앱 URL** 을 복사

> URL 형식: `https://script.google.com/macros/s/.../exec`

## 4. 웹사이트에 URL 등록

1. 웹사이트 로그인 (관리자 계정)
2. **설정** 탭 → **☁️ 클라우드 동기화** 카드
3. 복사한 URL 을 입력 후 **연결 테스트** 클릭
4. `✓ 연결 성공` 이 뜨면 **설정 저장** 클릭
5. **지금 전체 동기화** 버튼으로 기존 데이터를 클라우드에 푸시

## 5. 시공사 계정도 같은 URL 사용

- 각 시공사 PC 에서 웹사이트 접속 → 로그인 → (자동으로 클라우드에서 데이터를 받아옴)
- 시공사는 URL 을 따로 입력할 필요 없습니다 (관리자가 배포한 사이트 코드에 이미 내장되어 있는 경우) 
- 만약 시공사도 URL 을 직접 입력해야 한다면: 관리자가 URL 을 전달 → 시공사는 로그인 후 계정 정보 영역에서 입력 (또는 관리자가 사이트 코드 `js/config.js` 의 `CLOUD_SYNC_URL` 에 URL 을 하드코딩해서 배포하면 모든 사용자에게 자동 적용)

## 구조

- **Google Sheet** 에는 `Submissions`, `Projects` 두 시트가 자동 생성됩니다
- **Google Drive** 에 `한전불입_첨부파일` 폴더가 생성되며, 그 안에 `[시공사명]/[프로젝트ID]_[프로젝트명]/` 구조로 파일이 자동 정리됩니다
- 파일명은 `[프로젝트ID]_[프로젝트명](-거점)_[문서종류].pdf` 형식으로 자동 변경됩니다

## 재배포 주의사항

Apps Script 코드를 수정한 뒤에는:
1. 저장 (Ctrl+S)
2. **배포 → 배포 관리** → 연필 아이콘(수정) → 버전을 **새 버전** 으로 설정 → 배포
3. URL 은 그대로 유지됩니다

새 배포를 누르면 URL 이 바뀌니, **반드시 "배포 관리"** 에서 기존 배포를 수정하세요.
